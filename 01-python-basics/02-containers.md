# 第二课:容器类型 list / tuple / dict / set

## 知识要点

| 容器 | 有序 | 可变 | 可索引 | 说明 |
|---|---|---|---|---|
| `list` | ✅ | ✅ | ✅ | 最常用,可混合类型 |
| `tuple` | ✅ | ❌ | ✅ | 不可变的 list;多返回值本质是 tuple |
| `dict` | ✅(3.7+ 按插入顺序) | ✅ | 用键 | 键值映射,≈ R 的具名 list |
| `set` | ❌ | ✅ | ❌ | 自动去重,查找极快 |

### 与 R 冲突最大的三点

**1. 索引从 0 开始**

```python
x = [10, 20, 30, 40, 50]
x[0]     # 10   (R 里是 x[1])
x[-1]    # 50   负索引 = 从末尾数;R 里 x[-1] 是"删除第一个"
```

**2. 切片左闭右开**

```python
x[1:3]   # [20, 30]   取索引 1、2,不含 3;元素个数 = 3 - 1
x[:2]    # [10, 20]
x[::-1]  # 反转
```

**3. 赋值是引用,不是复制**

```python
a = [1, 2, 3]
b = a           # b 和 a 指向同一个对象
b[0] = 99
print(a)        # [99, 2, 3]  ← a 也变了

c = a.copy()    # 真正复制
```

R 是 copy-on-modify,改 `b` 不影响 `a`;Python 的 list 是可变对象,`b = a` 只是多一个名字。

### 常用操作

```python
lst.append(4)          # 末尾添加
lst.insert(0, 99)      # 指定位置插入
lst.remove(99)         # 按值删除
lst.pop()              # 删除并返回最后一个
len(lst)
3 in lst               # 成员判断

person = {"name": "Alice", "age": 25}
person["name"]
person["city"] = "BJ"  # 新增键
person.keys(), person.values(), person.items()

a, b, c = (1, 2, 3)    # 解包
```

## 我问过的问题

### set 的输出顺序为什么和输入不同?

```python
print({'a', 'a', 'b', 2, 2, 3, 3})
# {3, 2, 'b', 'a'}
```

- set 是**无序集合**,底层是哈希表,元素存放位置由哈希值决定,与输入顺序无关
- 用"放弃顺序"换取 O(1) 的查找和去重
- 因此 **set 不能索引**(`s[0]` 报错),也不要依赖它的顺序
- 小整数看起来有序,是因为 `hash(n) == n`,属于实现细节
- 需要"去重 + 保留顺序"时:`list(dict.fromkeys(items))`
