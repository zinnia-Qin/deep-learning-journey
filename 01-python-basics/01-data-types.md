# 第一课:基础数据类型

## 知识要点

### 赋值与动态类型

- 赋值用 `=`(没有 R 的 `<-`),相等判断用 `==`
- 动态类型:变量无需声明类型,类型由值决定,可随时改变

### 四种标量类型

| 类型 | 含义 | 示例 |
|---|---|---|
| `int` | 整数,**任意精度,不溢出** | `25`、`2 ** 100` |
| `float` | 双精度浮点 | `1.75` |
| `str` | 字符串 | `"Alice"` |
| `bool` | 布尔 | `True` / `False` |

### 与 R 的关键差异

| 项目 | R | Python |
|---|---|---|
| 标量 | 长度为 1 的向量,`length(25)` 为 1 | 真标量,`len(25)` 报 `TypeError` |
| 布尔值 | `TRUE` / `FALSE`,可简写 `T` / `F` | `True` / `False`,首字母大写,无简写 |
| 幂运算 | `^` | `**` |
| 空值 | `NULL` | `None`,判断用 `is None` |
| 缺失值 | `NA` | 纯 Python 无对应;NumPy 用 `np.nan` |

### 类型检查与转换

```python
type(25)                # <class 'int'>,类似 R 的 class()
isinstance(25, int)     # True,条件判断时推荐用它(能处理继承)

int("25")               # 25
float("3.14")           # 3.14
str(25)                 # "25"
int(3.9)                # 3   ← 截断,不是四舍五入
round(3.9)              # 4
round(2.5)              # 2   ← 四舍六入五成双,与 R 一致
```

### 字符串

- 单引号、双引号等价
- **字符串不可变**:`s[0] = "H"` 报错,只能生成新字符串 `s = "H" + s[1:]`
- f-string 格式化:

```python
name, score = "Bob", 87.6543
f"{name} 的分数是 {score:.2f}"     # 'Bob 的分数是 87.65'
```

### 算术运算

```python
7 / 2      # 3.5
6 / 2      # 3.0   ← / 永远返回 float
7 // 2     # 3     整除(类似 R 的 %/%)
7 % 2      # 1     取余
2 ** 10    # 1024
```
