# 第八课:索引、切片、布尔索引

数据:一组样地每木调查记录,几个等长数组按位置一一对应。

```python
dbh = np.array([12.5, 34.0, 8.2, 45.6, 22.1, 5.4, 18.9, 30.3])     # 胸径 cm
species = np.array(["麻栎", "青冈", "枫香", "麻栎", "青冈", "枫香", "马尾松", "青冈"])
```

## 知识要点

### 一维索引与切片:规则同列表

```python
dbh[0]      # 第一个,从 0 开始
dbh[-1]     # 最后一个
dbh[1:4]    # 索引 1、2、3,左闭右开
```

### 切片是视图,不是副本

```python
s = dbh[:3]
s[0] = 999
dbh[:3]          # [999.  34.  8.2]  原数组被改了
```

| | 取子集后修改,影响原对象吗 |
|---|---|
| R 向量 | 不影响 |
| Python 列表切片 | 不影响 |
| **NumPy 切片** | **影响** |

需要独立副本时用 `.copy()`。

### 二维索引 `[行, 列]`

```python
trees = np.array([[12.5,  9.8],     # 列 0:胸径,列 1:树高
                  [34.0, 18.2],
                  [ 8.2,  6.1],
                  [45.6, 22.4]])

trees[1, 0]        # 34.0
trees[:, 0]        # 所有树的胸径;取全部行时冒号不能省
trees[1:3, :]      # 第 2、3 棵树
trees[:, 0].shape      # (4,)    单个整数取列:降为一维
trees[:, [0]].shape    # (4, 1)  列表或切片取列:保持二维
```

### 花式索引:整数列表取多个位置

```python
dbh[[0, 3, 5]]     # 返回副本
```

### 布尔索引

```python
dbh[dbh >= 10]                     # 筛选,同 R
(dbh >= 10).sum()                  # 计数
(dbh >= 10).mean()                 # 比例
species[dbh >= 30]                 # 用一个数组的条件筛选另一个数组
dbh[species == "青冈"]
dbh[np.isin(species, ["麻栎", "青冈"])]    # ≈ R 的 %in%
```

**组合条件:用 `&` `|` `~`,每个条件加括号。**

```python
dbh[(dbh >= 10) & (dbh < 30)]
dbh[dbh >= 10 & dbh < 30]          # TypeError: ufunc 'bitwise_and' not supported
```

`&` 优先级高于 `>=`,不加括号会先算 `10 & dbh`。`and` / `or` 只用于单个 True/False。

### 按条件赋值、二选一、多选一

```python
dbh_clean = dbh.copy()
dbh_clean[dbh_clean < 5] = np.nan

np.where(dbh >= 10, "乔木", "幼树")                  # ≈ R 的 ifelse()
np.select([dbh < 10, dbh < 30], ["小径木", "中径木"], default="大径木")
```

### 按某列条件筛选行

```python
trees[trees[:, 0] >= 10]
```

`trees[:, 0] >= 10` 每行一个 True/False,用来选**行**,被选中的行**整行保留**。

## 我问过的问题

### `trees[trees[:, 0] >= 10]` 为什么保留了 `[12.5, 9.8]`?9.8 小于 10 啊

条件只检查第 0 列(胸径)。这一行胸径 12.5 ≥ 10,所以整行保留;9.8 是**树高**,条件没有看它。

我把"第 0 列"记成了第二列:**NumPy 的行、列都从 0 开始,第 0 列就是第一列**。

两列都要满足时:

```python
trees[(trees[:, 0] >= 10) & (trees[:, 1] >= 10)]
```

对比 `trees[trees >= 10]`:条件作用于每个元素,结果展平成一维,行结构丢失,筛选数据时一般不用。

| 写法 | 条件形状 | 选的是 | 结果 |
|---|---|---|---|
| `trees[trees[:, 0] >= 10]` | (4,) | 行 | 二维,整行保留 |
| `trees[trees >= 10]` | (4, 2) | 单个元素 | 一维 |

记列号的小技巧:`DBH, HEIGHT = 0, 1`,然后写 `trees[:, DBH]`。

数据:

```python
dbh = np.array([15.2, 6.8, 28.4, 41.0, 9.5, 19.7, 33.1, 4.2, 22.6, 12.3])
height = np.array([11.2, 5.9, 17.5, 21.3, 7.4, 13.8, 19.6, 4.1, 15.0, 9.9])
species = np.array(["麻栎", "枫香", "青冈", "麻栎", "枫香", "青冈", "麻栎", "枫香", "马尾松", "青冈"])
```

### 第 1–7 题 ✅ 全部正确

```python
# 1. 第 3 到第 6 棵树的胸径
dbh[2:6]                                        # [28.4 41.  9.5 19.7]

# 2. 胸径 ≥ 5 cm 的株数与比例
(dbh >= 5).sum()                                # 9
(dbh >= 5).sum() / len(dbh)                     # 0.9,也可写 (dbh >= 5).mean()

# 3. 麻栎的树高与平均树高
height[species == "麻栎"]                        # [11.2 21.3 19.6]
height[species == "麻栎"].mean()                 # 17.37

# 4. 胸径在 [10, 30) 的树种
species[(dbh >= 10) & (dbh < 30)]               # ['麻栎' '青冈' '青冈' '马尾松' '青冈']

# 5. 麻栎或青冈,且胸径 ≥ 20
dbh[(np.isin(species, ["麻栎", "青冈"])) & (dbh >= 20)]   # [28.4 41.  33.1]

# 6. 径级标签
np.where(dbh < 10, "小径木", np.where(dbh < 30, "中径木", "大径木"))
```

🔍 **改进**:径级多时用 `np.select` 更易读:

```python
np.select([dbh < 10, dbh < 30], ["小径木", "中径木"], default="大径木")
```

```python
# 7. 树高 > 15 m 的行
trees = np.column_stack([dbh, height])
trees[(trees[:, 1] > 15),]          # 我的写法
```

🔍 **问题**:末尾的逗号是 R 习惯(`m[cond, ]`)。在 Python 里它把条件包成了 tuple,恰好能运行,但不是惯用写法。

✅ `trees[trees[:, 1] > 15]` 或显式写出所有列 `trees[trees[:, 1] > 15, :]`

### 第 8 题:视图与副本

```python
a = dbh[:3]
b = dbh[[0, 1, 2]]
a[0] = 100
b[1] = 200
print(dbh[:3])
```

❌ **我的预测**:`100, 200, 2`

✅ **实际结果**:`[100.    6.8  28.4]`

🔍 **分析**
- `a = dbh[:3]` 是切片 → **视图**,`a[0] = 100` 改的就是 `dbh[0]` ✅
- `b = dbh[[0, 1, 2]]` 是花式索引 → **副本**,`b[1] = 200` 不影响 `dbh`,`dbh[1]` 仍是 6.8
- `dbh[2]` 没有被修改,仍是 28.4;`print` 打印的是值,不是索引

切片只需记"起点、步长、个数"就能指向原数据;整数列表可以是任意位置和顺序,只能复制。

| 取法 | 例子 | 结果 | 修改会影响原数组吗 |
|---|---|---|---|
| 切片 | `dbh[:3]`、`trees[:, 0]` | 视图 | **会** |
| 整数列表 | `dbh[[0, 1, 2]]` | 副本 | 不会 |
| 布尔索引 | `dbh[dbh >= 10]` | 副本 | 不会 |

> 实用原则:打算修改取出来的部分时,一律先 `.copy()`。

## 本课要点

> - 一维索引切片同列表;二维 `arr[行, 列]`,行列都从 0 开始,取全部行写 `:`
> - **切片是视图**,整数列表和布尔索引是副本;要修改就先 `.copy()`
> - 单个整数取列降为 `(n,)`,`[[0]]` 保持 `(n, 1)`
> - 布尔索引 `arr[条件]`;`.sum()` 计数,`.mean()` 比例;`np.isin` 多值匹配
> - **组合条件用 `&` `|` `~`,每个条件加括号**
> - `np.where` 二选一,`np.select` 多选一
> - `arr[arr[:, 0] >= 10]` 按某列筛选行,整行保留
