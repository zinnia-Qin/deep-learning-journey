# Deep Learning Journey

> 从 R 用户转向 Python 深度学习的学习记录
> A learning log: from R to Python, NumPy and PyTorch

## 背景

- 已完成 Andrew Ng 的 Deep Learning Specialization(五门课)
- 有扎实的 R 基础,Python 基础较薄弱
- 学习路线:**Python 核心 → NumPy → PyTorch**

本仓库记录每一课的知识要点、我的练习答案,以及**做错的地方和原因**。
错误标注是这个仓库最有价值的部分:它们大多来自 R 的思维习惯,
对同样从 R 转 Python 的人可能也有参考价值。
